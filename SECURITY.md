# Security Policy

## Reporting a vulnerability
Please do not open a public issue for security problems. Email **support@lakshyapocketlab.com** with the subject "Security" and include:
- the affected repository or service and version,
- steps to reproduce, and the impact you see.

We will acknowledge your report, keep you updated and credit you when the fix ships, if you wish.

## Please never share
API keys (`hello_live_...`), access tokens or customer data in a report. If a key may be exposed, delete it in the Hello dashboard and create a new one.
