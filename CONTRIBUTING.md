# Contributing

Thanks for helping improve Hello. These guidelines apply to every Lakshya Pocket Lab repository unless it has its own.

## Report a problem or suggest an idea
- Search existing issues first, then open one with the bug report or feature request form.
- For a bug, include what you ran, what you expected and what happened. Never paste API keys (`hello_live_...`) or customer data.
- For security issues, do not open a public issue. See [SECURITY.md](SECURITY.md).

## Send a pull request
1. Fork the repository and create a branch with a descriptive name, for example `fix/retry-after-parsing`.
2. Keep the change focused. Add or update tests; our SDKs aim for full test coverage.
3. Run the repository's checks (linter and tests) before pushing.
4. Open a pull request and fill in the template. Explain the why, not just the what.

## Style
Follow the conventions already in the code. Write clear commit messages in the imperative mood.
